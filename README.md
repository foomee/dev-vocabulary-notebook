# ①課題名
プログラミング頻出英単語帳

## ②課題内容（どんな作品か）
プログラミング学習中に頻出する単語を覚えるものです。 

## ③アプリのデプロイURL

## ⑤工夫した点・こだわった点
- CSS変数というものを使ってみました。
- 単一のページじゃなくて、複数のページがあるサイトを作ってみました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- ユーザーによる単語の追加は時間が間に合いませんでした。
- 単語の検索機能も付けたかったです。
- 前回の課題よりは構造が複雑ではないと思いますが、複数ページを作ったことによりコードの管理が大変でした。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
自分がプログラミングの勉強しているときに見慣れない単語が出てくると、その度に脳のリソースを使ってしまう感じがありました。
自分以外でもそう感じている人は多いだろうと思って、その問題を解決できればと思ってこのアプリを作りました。
